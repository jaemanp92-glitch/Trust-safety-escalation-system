# 🚨 Trust & Safety Escalation Review System

A simulated escalation review workflow system designed for Trust & Safety operations.

## 🔗 Live Demo
https://trust-safety-escalation-system.streamlit.app

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas

## ✨ Features
- Escalation queue management
- Risk score analysis
- Moderator review workflow
- Final enforcement decision system
- Trust & Safety case simulation

## 📌 Purpose
This project simulates how high-risk moderation escalations are reviewed in real-world Trust & Safety environments.
